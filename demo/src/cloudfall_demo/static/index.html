How it works

The model is live

Each run calls Nemotron on Nebius Token Factory through cloudfall agent investigate. Pick Lightning and you may watch it try to wipe the database.

The host is recorded

The incident ran on a real Hetzner cx23: 36G of unrotated shop logs filled the disk and PostgreSQL went down. Every read and check the model asks for is played back from that host, so nothing here touches a server.

Your approval is the gate

Reads run freely. Changes run in check mode and wait. Approving plays back the approval recorded on the same host: the fix ran, its verify step passed, the disk went from 100% to 5%.

Everything is on the record

Each investigation is saved with the model, the tokens and every call; each decision with its diff, its approver and its verify result. cloudfall why answers why the agent did that.

Cloudfall is open source (AGPL-3.0). Built for the Nebius × NVIDIA Global AI Hackathon. Runs are limited per visitor and per day.
