### Added

- `services.yml` converges a PostgreSQL database owned by a declared role: it creates the `owner` login role, sets its password from `passwordRef` as SCRAM-SHA-256 on every converge, and gives it the database; backups, the restore drill, and `data copy` (restoring as the owner, its receipt's `spec.owner`) cover it like any other database. Every path that runs `services.yml` (the `converge_services` MCP tool, the `services` step of `cloudfall migrate`, `operator approve` and `operator run`, and `cloudfall-engine playbook run services.yml`) reads the password from a `--secrets-dir` flag (default `secrets`) and stages it in a 0600 file in a private temp dir outside the project, removed after the run; the value is in no inventory, command line, Ansible output, answer, or receipt, and the answer's `owned_roles` names the reference, the key, and the value's SHA-256. A missing secrets file or key fails with `PRECONDITION` naming the expected path and key before any playbook runs (#122)
