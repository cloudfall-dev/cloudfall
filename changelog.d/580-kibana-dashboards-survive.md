### Added

- Kibana's dashboards survive a snapshot restore and a rebuilt server (S-024-10, S-024-11): when a Kibana service reads an Elasticsearch service, `cloudfall-elasticsearch-backup` checks that the snapshot it took lists the feature state `kibana`, where Kibana keeps its saved objects, and fails the run when it does not; the snapshot request is unchanged, and a cluster without Kibana renders and runs its backup script as before. The new `docs/kibana-service-guide.md` gives the restore (stop Kibana, restore the feature state `kibana` alone from a snapshot, start Kibana) and what a rebuilt Kibana server gets: the same three encryption keys from the project's store, so encrypted saved objects still decrypt, and a new service token in the rebuilt node's own `service_tokens` file (#580)
