### Security

- A declared operation's check diff and the logs of its approved run and verify step are no longer written to the committed `decisions/` directory: they go to the project's ignored `tmp/output/decisions/` (`0600`), and the decision record keeps each file's path, sha256 and size as before, so a secret a team's playbook prints with `--diff` (a templated password without `no_log` or `diff: false`) never reaches git. A `--decisions` folder elsewhere in the project keeps its output under the same path below `tmp/output/`; one already under `tmp/` keeps it beside its records. `decisions approve` refuses with `PRECONDITION` and `decision_diff_missing`, naming the file and its sha256, when the raw diff is not on this machine, such as on another clone. Records written before keep citing their files in `decisions/` and are read and approved in place; a file of theirs already committed stays in git's history, so one that may hold a secret is for you to purge (#357)
